# MCP v2 Client API Reference

| Status & Link | Code | API Type | Safety / Status | Description |
| :---: | :--- | :--- | :--- | :------------------------------------------------------------------------------------------------------------------- |
| &cross; [link](src/mcp_client_v2/system/handlers.py#L15-L24) | `StdioServerParameters(command, args, env)` | Python SDK | Active | Configures executable paths, runtime arguments, and isolated environment variables to spawn a local server subprocess. |
| &cross; [link](src/mcp_client_v2/system/handlers.py#L28-L33) | `stdio_client(server_params)` | Python SDK | Active | Use `stdio` when both client and server are hosted on the same machine. Auto-spawns the server process and pipes input/output. |
| &cross; | `sse_client(url)` | Python SDK | **Legacy / Deprecated** | Legacy HTTP transport client. `sse` is getting deprecated; use `streamable_http_client` when client & server are on different machines, or `stdio_client` when on the same machine. |
| &check; [link](src/mcp_client_v2/system/handlers.py#L39) | `streamable_http_client(url)` | Python SDK | Active | Use `streamable-http` when client and server are hosted on different/remote machines over HTTP network. *(Note: Python SDK does not have `mcp.streamable_http()`; client function is `streamable_http_client(url)`).* |
| &check; [link](src/mcp_client_v2/system/handlers.py#L40) | `ClientSession(read, write)` | Python SDK | Active | Core client session manager handling JSON-RPC message serialization, request tracking, and stream lifecycle. |
| &check; [link](src/mcp_client_v2/system/handlers.py#L41) | `await session.initialize()` | Official MCP Spec | Active | Protocol handshake negotiating version negotiation, client/server capabilities, and metadata exchange. |
| &check; [link](src/mcp_client_v2/system/handlers.py#L45-L48) | `await session.send_ping()` | Official MCP Spec | Active | Heartbeat ping verifying that the remote server process and communication transport are active and responsive. |
| &cross; [link](src/mcp_client_v2/system/handlers.py#L51-L58) | `await session.set_logging_level(level)` | Official MCP Spec | **Deprecated (SEP-2577)** | Notifies the server of minimum log level (`info`, `debug`). **Note:** Deprecated as of 2026-07-28; use standard server-side structured logging / OpenTelemetry instead. |
| &check; [link](src/mcp_client_v2/tools/handlers.py#L8-L10) | `await session.list_tools()` | Official MCP Spec | Active | Sends `tools/list` request to discover all callable tools, descriptions, and input schemas exposed by server. |
| &check; [link](src/mcp_client_v2/tools/handlers.py#L13-L15) | `await session.call_tool(name, arguments)` | Official MCP Spec | Active | Sends `tools/call` request to execute a remote tool with structured parameters and returns a `CallToolResult`. |
| &check; [link](src/mcp_client_v2/resources/handlers.py#L8-L10) | `await session.list_resources()` | Official MCP Spec | Active | Sends `resources/list` request to discover all fixed, static resource URIs exposed by the server. |
| &check; [link](src/mcp_client_v2/resources/handlers.py#L13-L15) | `await session.list_resource_templates()` | Official MCP Spec | Active | Sends `resources/templates/list` request to discover dynamic URI schemas with wildcards (e.g. `schema://db/{table}`). |
| &check; [link](src/mcp_client_v2/resources/handlers.py#L18-L20) | `await session.read_resource(uri)` | Official MCP Spec | Active | Sends `resources/read` request to retrieve static or templated resource contents from the server. |
| &check; [link](src/mcp_client_v2/resources/handlers.py#L23-L25) | `await session.subscribe_resource(uri)` | Official MCP Spec | Active | Subscribes client to push notifications from the server whenever the specified resource is updated. |
| &check; [link](src/mcp_client_v2/resources/handlers.py#L28-L30) | `await session.unsubscribe_resource(uri)` | Official MCP Spec | Active | Cancels active resource subscriptions to stop receiving update notifications. |
| &check; [link](src/mcp_client_v2/prompts/handlers.py#L7-L9) | `await session.list_prompts()` | Official MCP Spec | Active | Sends `prompts/list` request to discover all reusable server prompt templates and expected argument keys. |
| &check; [link](src/mcp_client_v2/prompts/handlers.py#L12-L16) | `await session.get_prompt(name, arguments)` | Official MCP Spec | Active | Sends `prompts/get` request to compile a prompt template with client-supplied variables into formatted messages. |
| &check; [link](src/mcp_client_v2/completions/handlers.py#L7-L13) | `await session.complete(ref, argument)` | Official MCP Spec | Active | Sends `completion/complete` request to fetch auto-complete suggestions for prompt arguments or template variables. |
