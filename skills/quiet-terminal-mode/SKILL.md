# Quiet Terminal Mode

## Core Directives
- **Zero Verbosity:** Never emit long summaries, conversational filler, duplicate content, or intermediate explanations in chat responses or terminal output.
- **Single-Sentence Confirmations:** When an action or file operation completes, provide only a single concise confirmation sentence with the relevant file link.
- **Save Tokens:** Avoid repeating file contents or architectural diagrams in conversational responses unless explicitly requested by the user.
